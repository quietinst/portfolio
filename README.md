# Portfolio

🔗 [Live demo](https://portfolio-khaki-zeta-75.vercel.app)

My personal portfolio website: a short intro, my skills, and selected projects.

Built with React and TypeScript.

## Pages

- **Home** — introduction, social links, CV download
- **Skills** — technologies I work with
- **Projects** — selected projects with links to the live versions

## Tech stack

- React + TypeScript
- Vite
- React Router
- Sass (SCSS), BEM
- typed.js

## Getting started

```bash
npm install
npm run dev
```
